## 🔧 Progetti

Progetti accademici sviluppati end-to-end (analisi, progettazione, sviluppo e test), successivamente evoluti con il supporto di IA generativa, introducendo nuove architetture e stack tecnologici per migliorarne funzionalità, robustezza e sicurezza.

- **[GetYourPC](https://github.com/Alessio-Colantoni/GetYourPC)** — piattaforma per la pubblicazione di annunci di compravendita di PC. Stack: Java, BCE, MVC, JavaFX, MySQL, Maven, API REST (Geoapify), JUnit, SonarQube, Figma, Git/GitHub. Evoluta con Spring Boot, Vue 3, PostgreSQL, Mailjet, Docker, Aiven, Render.<img width="499" height="49" alt="image" src="https://github.com/user-attachments/assets/d3abe319-6791-467f-9295-e8c43fcaa61d" />

- **[CRM](https://github.com/Alessio-Colantoni/CRM)** — piattaforma CRM. Stack: Java, MVC, MySQL, Maven, Git/GitHub. Evoluta con Spring Boot, API REST, Vue 3, Docker, Aiven, Render.<img width="499" height="37" alt="image" src="https://github.com/user-attachments/assets/28f1d710-d9ab-462b-a40c-b9916e2c23af" />

- **[AlfaPizza](https://github.com/Alessio-Colantoni/AlfaPizza)** — app Android sviluppata in team per la gestione dei turni dei rider di pizzerie, con generazione calendari in base a vincoli e preferenze. Stack: Kotlin, MVVM, Jetpack Compose, Firebase Storage, API REST, Git/GitHub. Evoluta con backend Node.js, MongoDB Atlas, GitHub Actions, Render.<img width="499" height="49" alt="image" src="https://github.com/user-attachments/assets/a21f6ccf-2175-4b02-9aaa-7eaeb0655525" />
